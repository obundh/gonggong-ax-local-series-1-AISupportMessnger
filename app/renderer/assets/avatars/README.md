# Avatar assets

이 폴더에는 현재 공개 명단에 사용하는 생성형 프로필 이미지만 포함합니다. 기존 HEYU 명단 10명은 원래 배정을 유지하고, 새 담당 김자원은 얼굴이나 사람이 나오지 않는 추상 문서 자원 이미지로 추가했습니다.

- `lawai.png`: 김법률
- `hangjeongai.png`: 김행정
- `langai.png`: 김국어
- `byeonghwanai.png`: 김병환
- `languageai.png`: 김언심
- `geurimai.png`: 김그림
- `sokgiai.png`: 김속기
- `jawonai.png`: 김자원 (비인물 추상 이미지)
- `gaeboai.png`: 김개보
- `routineai.png`: 김루틴
- `noriai.png`: 김노리

11개 파일은 공개본 편입 전에 로컬 경로, 사용자명, GPS 위치, EXIF/XMP 기기 정보가 없는지 확인해야 합니다. 일부 PNG에는 생성형 이미지 출처를 나타내는 C2PA 기록이 있으며, 이는 삭제하지 않고 보존합니다.

목록에 없는 PNG/JPG/WebP 파일은 기본 `.gitignore`에 의해 커밋되지 않으며, 공개 릴리스 감사도 허용 목록 밖의 아바타를 거부합니다.
