# 김속기 로컬 STT 설정

김속기는 한국어·영어 받아쓰기를 로컬 `whisper.cpp` 프로세스로 처리합니다. Windows 설치본에는 whisper.cpp 1.9.2, `large-v3-turbo-q5_0`, Silero VAD를 포함하며 새 사용자 데이터에서도 인터넷 연결 없이 Turbo 프로필을 기본 선택합니다. Turbo는 한국어 품질을 우선하지만 PC에 따라 무거울 수 있습니다. 선택한 로컬 LLM이 Gemma4 e4b 이상으로 식별되지 않으면 화면에서 Lite·영어용 `small-q5_1`을 권장하는 주의 문구를 표시합니다. 대용량 자산은 Git에 커밋하지 않고 빌드 시 고정 출처에서 받아 검증 후 설치본에 넣습니다.

공식 출처:

- whisper.cpp 1.9.2: <https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.2>
- whisper.cpp 변환 모델: <https://huggingface.co/ggerganov/whisper.cpp>
- OpenAI large-v3-turbo 모델 카드: <https://huggingface.co/openai/whisper-large-v3-turbo>
- whisper.cpp VAD 안내: <https://github.com/ggml-org/whisper.cpp#voice-activity-detection>

실제 빌드 출처와 체크섬은 `app/main/stt-catalog.cjs`가 단일 기준입니다. 빌드 준비 스크립트만 HTTPS 허용목록을 사용하며, 설치된 앱의 STT 관리자에는 네트워크 설치가 기본적으로 비활성화되어 있습니다. ZIP은 경로 탈출, 심볼릭 링크, Windows 장치명과 충돌 경로를 추출 전에 검사하고, 설치본에는 카탈로그가 지정한 필수 실행파일과 DLL만 포함합니다. 앱은 동봉 파일도 사용 전에 다시 SHA-256으로 확인합니다.

동봉되지 않은 모델은 `파일 선택·설치`로만 추가합니다. 파일 선택창은 메인 프로세스가 열고 렌더러에는 경로나 URL 대신 자산 ID와 결합된 짧은 수명의 일회성 토큰만 전달합니다. 설치 시 카탈로그의 정확한 바이트 수와 SHA-256을 다시 확인하고, 불일치 파일은 기존 설치를 바꾸지 않은 채 거부합니다. 폐쇄망 반입 파일은 조직에서 승인한 외부망 장비와 이동식 매체 절차로 확보해야 합니다.

## 프로필

- `기본`: 동봉된 `large-v3-turbo-q5_0`. 일반 한국어 회의에서 품질을 더 우선할 때 권장합니다.
- `Lite`: 사용자가 검토된 로컬 파일로 설치하는 `small-q5_1`. 저사양 CPU와 영어 음성에 권장하며 한국어 정확도는 상대적으로 낮을 수 있습니다.

내부 호환 코드에는 사용자가 환경변수나 기존 번들로 직접 둔 large-v3/medium 계열을 찾는 `정확` 프로필도 남아 있지만, 공개 화면의 자동 설치 목록에는 아직 노출하지 않습니다. 관리형 설치·선택 경로가 있으면 이를 먼저 사용하고, 관리형 구성요소가 없을 때만 기존 `HEYU_WHISPER_*` 경로를 호환용으로 확인합니다.

양자화 모델이 모든 한국어 녹음에서 더 정확하다는 보장은 없습니다. 기관의 실제 회의 샘플로 CER 또는 사람이 확인한 오류 수를 비교한 뒤 조직 기본값을 정하는 것이 안전합니다.

## 결과와 역할 경계

- 원문 받아쓰기와 AI 정리 초안을 별도 파일·단계로 취급합니다.
- 숫자, 날짜, 시각, 금액, 단위, 이름, 기관명과 타임스탬프는 정리 과정에서 보존합니다.
- 잘 들리지 않는 구간은 추측해 메우지 않고 불명확 표시 대상으로 둡니다.
- 속기 정리 요청은 현재 원문만 사용합니다. 사용자가 비교를 명시하지 않으면 이전 대화, 워크스페이스 검색 결과와 MCP 근거를 섞지 않습니다.

## 파일 보관

녹음과 결과는 설치 폴더가 아니라 사용자별 작업공간의 `audio`와 `transcripts` 폴더에 저장됩니다. 마이크 녹음이나 가져온 파일을 전사용 WAV로 변환한 `처리용 음성` 보관이 기본값이며, 사용자가 보관을 끈 작업만 성공한 전사 뒤 이를 삭제합니다. 가져온 원본 파일 자체를 별도로 복사·보관하는 기능은 아닙니다. TXT, SRT, VTT, JSON 결과는 각각 열어 검토할 수 있습니다.

민감한 회의는 녹음 동의, 내부 보관 기간, 접근권한과 파기 절차를 먼저 확인해야 합니다. 사용자 데이터 폴더의 파일은 Git 공개본에 포함되지 않습니다.

## 현재 범위

- Windows x64 CPU 공식 런타임을 기본 제공 경로로 지원합니다.
- NVIDIA CUDA용 whisper.cpp와 faster-whisper는 의존성·GPU 드라이버 조합을 별도로 검증해야 하므로 현재 범용 설치 목록에는 넣지 않았습니다.
- 고정된 녹음 시간 제한은 두지 않습니다. 마이크 녹음은 사용자가 `정지+STT`를 누를 때까지 계속되고, 15분이 지나도 자동 정지하지 않습니다.
- 현재는 전체 음성을 16kHz mono WAV와 base64로 메모리에 올립니다. 그래서 시간 대신 `녹음/STT` 용량 설정을 적용하며 기본값은 작업당 120MB입니다. 가져온 원본과 변환된 처리용 WAV를 모두 확인하고, 마이크 녹음은 이 용량 한도에 가까워지면 데이터 손실을 피하기 위해 자동 정지 후 받아쓰기를 시작합니다.
- 실제 처리 가능한 길이는 원본 코덱·샘플레이트와 설정한 용량에 따라 달라집니다. 긴 회의는 메모리 사용량과 처리 시간이 커지므로 필요하면 여러 파일로 나누는 편이 안전합니다. 향후 AudioWorklet/청크 기반 처리로 교체하면 이 부담을 더 줄일 수 있습니다.
