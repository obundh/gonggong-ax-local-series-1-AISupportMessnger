# AI지원담당 설치 전 웹 데모

처음 방문했다면 이 페이지 상단의 `Windows 다운로드`보다 먼저 데모를 눌러 보세요. 실제 친구목록과 같은 모양에서 담당자를 열고 기능 흐름을 확인할 수 있습니다. 설치파일은 [원클릭 다운로드](https://github.com/obundh/gonggong-ax-local-series-1-AISupportMessnger/releases/latest/download/AI-Support-Messenger-Setup-0.1.0.exe), 소개 영상은 [`assets/intro-video.mp4`](assets/intro-video.mp4), 설치 순서는 [고양이 6장 만화](../docs/comic/)에서 확인합니다.

설치 전에 AI지원담당의 실제 사용 흐름을 체험하는 정적 웹 페이지입니다. 왼쪽에서 예시 질문을 고르면 오른쪽의 실제형 친구 목록에서 담당자가 표시되고, 친구를 더블클릭하거나 Enter 또는 `채팅 열기` 버튼을 누르면 채팅창이 열립니다.

오른쪽 화면은 데스크톱 앱의 520×760 친구 창, 기본 96px 레일이 고정 창 폭에서 반응형으로 줄어든 실제 86px 아이콘 레일, 검색ㆍ분류 탭ㆍ업무지원/기술지원 목록을 모사합니다. 일반 담당은 520×760 채팅으로, 김병환ㆍ김그림ㆍ김속기ㆍ김자원ㆍ김개보ㆍ김루틴은 900×760 형태의 채팅과 우측 기능 패널로 이어집니다.

기능 패널의 대표 버튼은 실제로 화면 상태를 바꿉니다.

- 김병환: 샘플 PDF 병합ㆍ4~6쪽 나누기
- 김그림: 이미지 브리프ㆍ긍정/부정 프롬프트 작성
- 김속기: 녹음 시작ㆍ정지ㆍTurbo 받아쓰기 단계
- 김자원: 샘플 PPTX 분석ㆍ자원 분류ㆍ미리보기
- 김개보: 합성 창/텍스트의 개인정보 후보 검사
- 김루틴: 30회/무한 반복ㆍ승인 지점ㆍSeries 4 최근 기록

## 중요한 경계

- 실제 LLM, 로컬 MCP, Whisper, 파일 변환기, 이미지 생성기, Series 4에 연결되지 않습니다.
- 파일 업로드, 마이크 권한, 네트워크 요청, 사용자 입력 저장을 하지 않습니다.
- 모든 질문과 답변은 제품 기능을 설명하기 위해 미리 작성한 예시입니다.
- 법률·행정 답변은 실제 조회나 개별 사건의 결론이 아닙니다.
- 병합ㆍ저장ㆍ녹음ㆍ생성ㆍ검사ㆍ자동화 버튼은 DOM 상태만 바꾸며 결과 파일이나 운영체제 작업을 만들지 않습니다.

## 실행

web-demo 폴더의 index.html을 직접 열어도 동작합니다.

정적 서버에서 확인하려면 이 폴더에서 다음 명령을 실행합니다.

    python -m http.server 4173 --bind 127.0.0.1

그다음 브라우저에서 http://127.0.0.1:4173/ 을 엽니다.

## 배포

web-demo 폴더 안의 파일과 assets 폴더를 그대로 정적 호스팅의 공개 루트에 올리면 됩니다. 별도 빌드나 서버 프로그램은 필요하지 않습니다.

Cloudflare Pages나 Netlify처럼 _headers 파일을 지원하는 정적 호스팅에서는 동봉된 보안 헤더가 함께 적용됩니다. 다른 호스팅에서는 같은 Content-Security-Policy, Referrer-Policy, X-Content-Type-Options, Permissions-Policy 값을 서버 설정에 옮겨 주세요.

프로필 원본은 데스크톱 앱 파일을 바이트 그대로 복사해 출처 기록을 보존했습니다. 실제 화면은 초기 전송량을 줄이기 위해 160×160 WebP 파생본을 사용하며, assets/avatar-thumbs/manifest.json에 원본과 파생본의 SHA-256, 크기, 변환 조건을 기록합니다. 썸네일을 다시 만들 때는 저장소 루트에서 npm run build:web-demo-assets를 실행합니다.

외부 공개 전에는 프로젝트 자체 라이선스와 이미지 공개 권리 문서를 최종 확정해야 합니다.
