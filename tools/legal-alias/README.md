# 법령명·약칭 로컬 해석기

김법률이 사용자의 약칭·띄어쓰기 변형을 정식 법령명 후보로 바꾼 뒤 완전 로컬 법령 MCP에서 확인하도록 돕습니다. 이 색인은 법령명 라우팅 자료일 뿐 조문 근거나 법률 자문 자료가 아닙니다.

## 로컬 카탈로그 가져오기

원본 세 파일이 있는 폴더를 지정합니다. 가져오기 도구는 매니페스트의 파일 크기와 SHA-256, UTF-8 인코딩, 범주별 건수를 검증한 다음 `data/legal_alias/official-names.json`을 원자적으로 생성합니다.

```powershell
npm run legal:aliases:import -- --source "<세 파일이 있는 폴더>"
```

앱을 이미 실행 중이라면 다음 법률 질문부터 변경된 색인을 다시 읽습니다. 원본 TXT와 생성 색인은 `.gitignore` 대상이며 공개 Git·설치본에는 포함하지 않습니다. 원 저장소 URL과 재배포 라이선스를 확인하기 전에는 원본이나 전체 파생 색인을 배포하지 마세요.

패키지 환경에서 별도 색인을 쓰려면 `HEYU_LEGAL_ALIAS_INDEX`에 검증된 `official-names.json`의 절대경로를 설정합니다.

## 기본 별칭

공개 소스에는 `근기법`, `개보법`, `정보공개법`, `국계법`, `지계법`, `노조법` 등 소량의 독립 검수 규칙만 포함합니다. 외부망 동기화로 반입한 `data/legal_alias/official-aliases.json`이 있으면 국가법령정보센터의 공식 약칭도 무결성을 확인한 뒤 합칩니다. `노동법`은 단일 법령으로 고정하지 않고 연차·임금·단체교섭·퇴직금 등 쟁점으로 후보를 좁힙니다. 쟁점이 없거나 여러 후보가 남으면 로컬 검색도 임의 법령을 확정하지 않고 후보 확인을 요청합니다.
