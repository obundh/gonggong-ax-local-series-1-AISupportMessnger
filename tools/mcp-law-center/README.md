# 국가법령정보센터 온라인 MCP (폐쇄망 실행 금지)

국가법령정보센터 공동활용 Open API를 매 호출마다 직접 조회하는 stdio MCP 서버입니다. 기존 `tools/mcp-law`는 내려받은 로컬 인덱스를 검색하고, 이 서버는 로컬 법령 데이터 없이 외부 API에 검색어와 조회 식별자를 전송합니다.

## 설정과 실행

공동활용 신청으로 받은 OC는 파일·명령행 인수·MCP 설정 JSON에 적지 않고 실행 프로세스의 `LAW_OC` 환경변수로만 전달합니다.

```powershell
$env:LAW_OC="<발급받은 값>"
npm run mcp:law:center
```

저장소에는 OC 예시값이나 실제 값이 들어 있지 않습니다. 서버의 상태 리소스도 설정 여부만 반환합니다.

## MCP 기능

- `legal_search`: `law`, `prec`, `expc`, `decc`, `admrul`, `detc` 제목/본문 검색
- `law_get`: `id`, `mst`, `lid` 중 정확히 하나로 본문 조회, 선택 조문 또는 개인정보 없는 쟁점 구문으로 관련 구간 추출, 최대 글자 수 지정. 여러 쟁점 구문은 `|`로 구분합니다.
- `law-center://status`: 연결 방식, OC 설정 여부, 외부 전송과 응답 제한
- `law-center-grounded-answer`: 검색 후 본문을 확인하고 근거와 한계를 표시하는 프롬프트

## 보안·개인정보 경계

- 검색어와 조회 식별자는 `https://www.law.go.kr/DRF/lawSearch.do` 또는 `lawService.do`로 직접 전송됩니다.
- 주민등록번호, 휴대전화번호, 이메일, 사용자 홈 경로, 대표적인 비밀키 형태가 검색어에서 감지되면 전송 전에 거부합니다.
- OC가 포함된 요청 URL을 반환하거나 로그로 남기지 않습니다. 알려진 API 오류와 예외에서도 OC를 지웁니다.
- 요청은 15초 후 중단하며 리다이렉트를 허용하지 않습니다. 호출 시작 간격은 최소 250ms이고, 원문 응답과 도구 출력 크기에 상한이 있습니다.
- 공개 법령정보 조회 도구이며 법률 자문이나 기관의 최종 판단을 대신하지 않습니다.

## Electron 앱 연결 상태

김법률은 이 서버를 사용하지 않습니다. 김법률의 실행 경로는 `tools/mcp-law` 완전 로컬 MCP로 고정되어 있고, API는 외부망 corpus 준비 도구 `tools/official-law-sync`에서만 사용합니다.

이 서버는 아직 폐쇄망 전환이 끝나지 않은 김행정의 제한된 공식 근거 조회와 개발 호환성 때문에 임시로 남아 있습니다. 완전 폐쇄망 배포에서는 실행하거나 `LAW_OC`를 설정하지 마세요. 김행정까지 로컬 corpus로 전환한 뒤 패키지에서 제거할 대상입니다.

외부망에서 로컬 corpus를 준비할 때는 이 실시간 서버 대신 다음 수집기를 사용합니다.

```powershell
$env:LAW_OC="<발급받은 값>"
npm run legal:official:sync
Remove-Item Env:LAW_OC
```
